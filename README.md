# HIS 智慧医疗系统

覆盖预约接诊、顾客档案、电子病历、手术耗材、病房床位、库存管理与财务核对的一体化医疗管理系统。

采用 React + Ant Design、Node.js 和 SQLite，支持本地运行，内置虚构演示数据。

## 快速开始

需要 Node.js 22.13 或更高版本，在项目根目录执行：

```bash
npm ci
npm run dev
```

访问 http://localhost:3100。

## 常用命令

```bash
npm run build  # 构建
npm start      # 启动构建后的版本
npm test       # 运行测试
```

详细运行说明见 [使用指南](demo/README.md)，原项目资料见 [历史文档](docs/legacy-project.md)。

当前版本用于功能演示，数据保存在本地 SQLite。许可证见 [LICENSE](LICENSE)。
